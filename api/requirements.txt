#   Linux (x86_64, PyPI default wheel)  pip install torch        # CUDA build, also runs on CPU
#   Linux, CPU only                     pip install torch --index-url https://download.pytorch.org/whl/cpu
#   macOS                               pip install torch        # Metal (MPS) build
#   Windows + NVIDIA                    pip install torch --index-url https://download.pytorch.org/whl/cu124
# The Windows development venv this repository was built on used the cu124 index for every package; that
# belongs in the build script, not in a requirements file shared by three platforms.
